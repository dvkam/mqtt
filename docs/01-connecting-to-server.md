# Connecting to a broker

Use the supported MQTT 5 factories for new applications. The [README](../README.md) shows TCP and browser sessions. The [WebSocket guide](recipes/websockets.md) covers Node and browser transport options. The [custom transport guide](recipes/using-custom-transports.md) links to the packet transport contract.

Client operations return promises. See the [message delivery comparison](message-stream-comparison.md) for the callback, async iterator and Web Stream experiments.
